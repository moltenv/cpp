# Минимальный C++-клиент к llama-server

Демонстрационный пример преподавателя: одна строка из stdin → JSON → HTTP POST → текст ответа. Это основа для изучения HTTP-взаимодействия; сценарий собственного приложения и конфигурацию для обязательного задания студенты добавляют самостоятельно.

Перед запуском клиента **llama-server уже должен работать на `127.0.0.1:8080` с псевдонимом `--alias local-model`**. Инструкция запуска сервера находится в [материалах урока](../README.md). Клиент не запускает сервер и не загружает модель.

## Сборка и запуск

Нужны компилятор C++17, CMake 3.20+, Git и libcurl с заголовками. Например, на Ubuntu/Debian: `sudo apt install build-essential cmake git libcurl4-openssl-dev`. Способы подготовки инструментов для других ОС описаны в материалах урока. На Windows установите также libcurl, например через vcpkg, и передайте его toolchain в первую команду CMake.

`nlohmann::json` подключается через `FetchContent` с закреплённой версией `v3.11.3`, как в примере JSON из предыдущих уроков. Здесь скачивается компактный архив релиза вместо Git-репозитория с историей; этот вариант рекомендует [документация библиотеки](https://json.nlohmann.me/integration/cmake/#fetchcontent). При первой конфигурации нужен доступ к GitHub. Для HTTP используется установленная библиотека через `find_package(CURL REQUIRED)` и цель `CURL::libcurl`.

Из каталога `http_demo`:

```bash
cmake -S . -B build
cmake --build build
./build/local_chat
```

Введите строку, например `Объясни в одном предложении, что такое RAII.`, и нажмите Enter. В stdout появится фактический текст модели; конкретная формулировка может меняться. Приглашение и ошибки выводятся в stderr.

Для генератора Visual Studio используйте `cmake --build build --config Debug`, затем в PowerShell запустите `.\build\Debug\local_chat.exe`. При другом генераторе путь к исполняемому файлу может отличаться.

## Как устроен пример

- `build_request()` формирует JSON через `nlohmann::json`: `model = "local-model"`, одно сообщение с `role = "user"`, `stream = false`, `max_tokens = 64`. Кавычки и другие специальные символы экранируются при `dump()`.
- `http_post()` отправляет запрос на `/v1/chat/completions` и собирает ответ через callback libcurl. Тайм-аут соединения — 5 секунд, всего запроса — 180 секунд, чтобы дать время модели на CPU.
- `extract_text()` разбирает JSON, проверяет типы вложенных полей и извлекает `choices[0].message.content`.
- `CurlRuntime` отвечает за общую инициализацию libcurl, а `std::unique_ptr` с функциями удаления освобождает соединение и заголовки при любом выходе из HTTP-функции. Исключения внутри callback перехватываются на границе C API.

При недоступном сервере, тайм-ауте, HTTP-статусе, отличном от 200, некорректном JSON или отсутствующем/неверно типизированном поле текста программа сообщает об ошибке и возвращает код 1. Пустой ввод также считается ошибкой.
